# 经营看板 · 1.3

首页提供独立的经营筛选表单，不需要输入自然语言。上传或恢复数据后，
看板和分析工作台共用同一份经过校验的内存数据。

1. 选择实际字段支持的指标和业务分组。
2. 选择1–90天的开始/结束日期，点击应用；近7/14/30天以所选结束日为锚点。
3. 联动查看本期、前一等长窗口、相对变化、分组数量、每日趋势、分组占比、
   横向排名和每日经营日历。日历颜色只在当前选择内比较，不是统计异常检测。
4. 明细支持分组搜索、数值/名称排序、每页10行和导出搜索后全部分组CSV。
   CSV保留原始数值（relative_change和share为0–1比率），不导出页面显示缩写。

比率统一由共享引擎按总分子/总分母计算，不展示可加占比；零分母为不可计算。
前期不足时保留有效本期结果并显示具体缺失提示，不估算环比。缺少本期任一日×分组
记录时阻止看板计算。补零必须在导入环节明确确认。

UCI默认案例只有英国地区一个分组，因此占比为100%，这是真实数据结果。
上传自己的多分组报表后可查看分组比较；请勿把地区解释为营销渠道。

计算模型：dist/lib/dashboard.mjs。页面控制：dist/dashboard-ui.mjs。
图表复用共享引擎返回值，原始数据没有第三方图表服务请求。
顶栏分析报告仅在分析工作台显示，避免导出其他筛选范围的历史结果。

自动检查见tests/dashboard.test.mjs；真实模型质量、实际业务效果及企业级
多用户访问不在这次版本验收范围内。
