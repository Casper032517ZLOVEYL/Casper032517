# 数据与指标契约

|字段|类型|口径|
|---|---|---|
|date|文本 YYYY-MM-DD|自然日；必须真实有效|
|channel|1至80字符文本|与日期组成唯一键|
|impressions|非负整数|漏斗曝光量|
|clicks|非负整数|由曝光产生的点击|
|registrations|非负整数|由点击转化的注册量|
|orders|非负整数|同口径漏斗成交订单|
|revenue|非负金额，人民币|已支付GMV，不是净收入|
|cost|非负金额，人民币|同渠道投放成本|

同一日期/渠道不能重复。缺失和零必须分开处理。整数计数不接受布尔值。CSV支持中文表头映射（日期、渠道、曝光量、点击量、注册量、订单量、付费金额、投放成本）；数值文本使用十进制数字，不支持千分位、科学计数或货币符号。

## 八项指标

|指标|计算方式|
|---|---|
|GMV|Σrevenue|
|订单量|Σorders|
|注册量|Σregistrations|
|投放成本|Σcost|
|CTR|Σclicks / Σimpressions|
|注册CVR|Σregistrations / Σclicks|
|ROAS|Σrevenue / Σcost|
|客单价|Σrevenue / Σorders|

禁止直接平均各渠道比率。分母为零返回null，在界面中显示“不可计算”。ROAS不是利润率。

## 变化贡献

金额/计数：渠道本期值减前期值，所有渠道贡献之和等于总变化。

比率：渠道本期分子/全部本期分母 − 渠道前期分子/全部前期分母。贡献之和等于整体比率变化，但包含分母结构变化，不能当作渠道自身转化率变化，也不能证明因果。选择单渠道时整体分母只包含该渠道。

## 示例数据

`dist/sample.csv` 为种子20260922生成的42天×4渠道=168行合成漏斗数据。金额变化是人为设置的演示场景，不代表真实经营。重建命令：`python tools/generate_data.py`。

XLSX只读首表；拒绝公式与布尔业务字段，支持共享/内联字符串、标准ZIP压缩和标准日期制。复杂办公文件请先导出UTF-8 CSV。没有执行宏或公式的路径。
