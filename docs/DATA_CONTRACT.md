# 数据契约 · 1.2

本版处理用户上传的真实报表，也提供有来源的公开交易案例。合成漏斗仍可用于回归，不代表用户业务结果。

## 两类来源

|来源|必需|可选|关键约束|
|---|---|---|---|
|日×分组汇总|日期、至少一个数值指标|分组、其余数值指标|默认拒绝重复日×分组；确认是互不重叠的可加子维度后可合并|
|订单明细|日期、唯一订单ID、销售金额、完整导出声明|分组、订单状态白名单|一行一单，ID全文件唯一；商品行必须先按订单汇总；订单量由ID计数|

分组可以是渠道、地区或门店，用户负责说明业务含义；没有分组列时使用“全部业务”。不能把国家误称作获客渠道。订单ID只用于浏览器内去重，不保留在标准分析行。未映射的手机号、姓名、地址等列不会进入计算或模型。

## 标准分析行

|字段|类型|可用条件|
|---|---|---|
|date|有效 YYYY-MM-DD|必需|
|channel|1–80字符|必需，适配器可生成默认分组|
|impressions / clicks / registrations / orders|非负整数或null|来源有该字段才赋值；null不等于0|
|revenue / cost|单一币种非负金额或null|最多2位小数；不接受货币符号、百分号、科学计数|

单项不超过1e12，汇总越过JS安全整数精度时拒绝计算。金额以分汇总，避免0.1+0.2式的浮点累计。Excel将119.13序列化为119.12999999999999时，只修正小于受限浮点容差的表示噪声并在报告计数；1.005这类真实三位金额仍阻止导入。

日×分组分析行必须唯一。曝光≥点击≥注册≥订单只在用户显式选择“同一漏斗”时校验，而且须提供四项。跨新老用户口径的订单与注册不再强制组成漏斗。

旧CLI若不提供dataset，仍沿用1.1的完整八字段严格漏斗模式，兼容历史回归。

## 文件与日期

- 5 MB、20,000源行、100列、20个分组；标准行补齐后也不能超过20,000行。
- CSV：UTF-8 / GB18030（兼容常见GBK）、逗号/Tab/分号，支持引号、换行、BOM。XLSX读取首表，拒绝公式、布尔单元格和1904日期制。
- 选择YMD、DMY、MDY或Excel 1900日期序号。支持本地时分秒，按文本日期归日，**不自动换算时区**。带Z或时区偏移的时间先转为业务本地时间。
- 日期与金额格式不明确时阻止导入；CSV解码失败可切换编码重试。

## 金额与状态

币种可选CNY/GBP/USD/EUR/JPY/HKD，一份导入只能一个币种，不做自动换汇。此版本统一按2位金额精度处理。

销售金额口径：`gross`表示正向销售额，未验证支付；`paid`表示用户确认的已支付订单金额。两者都不等于扣退款后的净收入。系统不根据发票号推断已支付。

订单状态列可映射，按用户明确列出的状态值严格纳入，报告排除数量；状态列未映射时用户须预先筛选目标订单。不自动识别“成功/完成/支付”的相似含义。负金额、退货、混合币种或商品行不自动修改；应先按业务规则处理。

## 完整性与质量报告

导入前先检查、后确认，失败不覆盖原数据。错误报告记录源行号与原因，最多导出前100项，另记完整错误数。

报告包含源行、纳入、状态排除、日汇总合并、缺失补零、浮点表示修正、输出行数、忽略列、警告和口径。源行数=纳入+排除+错误行数；配置错误不对应数据行。

默认不补零。只有用户明确声明覆盖期、各分组导出完整且缺失确实代表无业务后才补齐。可声明起止日期以暴露尾部缺失；未声明时仅能依据原文件日期范围，**不能自动判断报表是否漏掉最后几天或整个分组**。平台覆盖范围仍需用户确认。

## 指标与时间窗口

|指标|计算|所需字段|
|---|---|---|
|销售金额（问题可使用GMV别名）|Σrevenue|revenue|
|订单 / 注册 / 成本|对应字段求和|orders / registrations / cost|
|CTR|Σclicks / Σimpressions|clicks、impressions|
|注册CVR|Σregistrations / Σclicks|registrations、clicks|
|ROAS|Σrevenue / Σcost|revenue、cost|
|客单价|Σrevenue / Σorders|revenue、orders|

缺字段时拒绝该指标；汇总证据中的缺字段保持null。零分母返回null，不参与有效排名，禁止平均渠道比率。

默认最近N天以整份数据最大日期为锚点。自选本期1–90天，前期为紧邻的等长窗口；问题显式天数与选择不一致时拒绝。比较要求两段完整，趋势/排名只要求本期；任何所需日×分组缺失都阻止计算。

金额/计数的渠道贡献为渠道前后差额；比率贡献为各渠道分子/全局分母之差，其和等于整体比率变化，包含分母结构变化，不证明因果。

## 真实公开案例

见[datasets/uci-manifest.json](../dist/datasets/uci-manifest.json)和[REAL_DATA.md](REAL_DATA.md)：英国地区2011年11月，GBP，26个有交易日、2,490张正向发票，用户界面按原公开全量交易覆盖声明补齐4个无交易日。没有支付状态、广告曝光/点击或投放成本，因此只开放销售额、订单量和客单价。
